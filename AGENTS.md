# Project instructions

## Implementation gates

- Follow `IMPLEMENTATION_WORKFLOW.md` for all project implementation.
- Do not begin the next phase until the current phase checkpoint is recorded as `PASS`.
- If a later failure invalidates an earlier contract, return to the earliest affected phase and rerun every downstream gate.

## Frontend work

- Before designing, implementing, restyling, polishing, or reviewing the frontend, load and follow the installed `design-taste-frontend` skill.
- Apply the skill's full art-direction and visual verification workflow to public-facing pages and landing/upload entry surfaces.
- Respect the skill's stated scope: it excludes dashboards and app screens, so do not force landing-page patterns onto the dense analyst dashboard. Use its generally applicable visual-quality and browser-review checks there while preserving dashboard usability, accessibility, and information density.
